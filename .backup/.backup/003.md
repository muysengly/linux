# 4. Create a virtual environment and install FastAPI and Uvicorn

###### 1. Create Virtual Environment

```bash
sudo apt-get update
sudo apt-get upgrade
sudo apt install python3-venv
python3 -m venv venv
source ~/venv/bin/activate
pip install "fastapi[standard]"
pip install uvicorn
pip install numpy
```

###### 2. Create FastAPI test

Create a file named `app.py` in your project directory with the following content:

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def read_root():
    return {"Hello": "World"}
```

## run the FastAPI test

```bash
uvicorn app:app --host 127.0.0.100 --port 8000 --reload

uvicorn app:app --host 0.0.0.0 --port 8001 --reload
```

# 5. Create a systemd service for FastAPI

###### 1. Make the `app.py` script executable

```bash
chmod +x app.py
```

###### 2. Create a systemd service file for FastAPI

Create a file named `app_my_app.service` in `/etc/systemd/system/`:

```bash
sudo nano /etc/systemd/system/app_my_app.service
```

Add the following content to the service file:

```ini
[Unit]
Description=FastAPI App
After=network.target

[Service]
User=muysengly
WorkingDirectory=/home/muysengly/app_my_app
ExecStart=/bin/bash -c 'source /home/muysengly/venv/bin/activate && uvicorn app:app --host 0.0.0.0 --port 8000 --reload'
Restart=always

[Install]
WantedBy=multi-user.target
```

###### 3. Enable and start the FastAPI service

Reload the systemd daemon to recognize the new service file:

```bash
sudo systemctl daemon-reexec
sudo systemctl daemon-reload
sudo systemctl enable app_my_app
sudo systemctl start app_my_app
```

Check the status of the FastAPI service:

```bash
sudo systemctl status app_my_app
```

###### 999. To remove the FastAPI systemd service:

```bash
sudo systemctl stop fastapi
sudo systemctl disable fastapi
sudo rm /etc/systemd/system/fastapi.service
sudo systemctl daemon-reload
```

# Connect Wifi via terminal

### Connect to WiFi via Terminal on Ubuntu Server

```bash
# install network-manager if not already installed
sudo apt install network-manager
```

```bash
# list available WiFi networks
nmcli dev wifi list
```

```bash
# connect to a WiFi network
nmcli dev wifi connect "Your-WiFi-SSID" password "Your-WiFi-Password"
```

```bash
# show all saved connections
nmcli connection show
```

```bash
# delete a known WiFi network
nmcli connection delete "WiFi-SSID"
```

```bash
nmcli device disconnect wlan0
```

```bash
# check connection status
nmcli device status
```
