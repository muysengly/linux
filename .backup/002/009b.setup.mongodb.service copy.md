## Install MongoDB using official repository (Recommended)

### Step 1: Install prerequisites

```bash
sudo apt update
sudo apt install -y wget curl gnupg
```

### Step 2: Import MongoDB GPG key

```bash
# For MongoDB 7.0 (latest stable)
wget -qO - https://www.mongodb.org/static/pgp/server-7.0.asc | sudo apt-key add -

# If the above fails, try:
curl -fsSL https://pgp.mongodb.com/server-7.0.asc | sudo gpg --dearmor -o /usr/share/keyrings/mongodb-server-7.0.gpg
```

### Step 3: Add MongoDB repository

```bash
# For Ubuntu 22.04 (Jammy)
echo "deb [ arch=amd64,arm64 signed-by=/usr/share/keyrings/mongodb-server-7.0.gpg ] https://repo.mongodb.org/apt/ubuntu jammy/mongodb-org/7.0 multiverse" | sudo tee /etc/apt/sources.list.d/mongodb-org-7.0.list

# For Ubuntu 20.04 (Focal) use:
# echo "deb [ arch=amd64,arm64 ] https://repo.mongodb.org/apt/ubuntu focal/mongodb-org/7.0 multiverse" | sudo tee /etc/apt/sources.list.d/mongodb-org-7.0.list
```

### Step 4: Update and install MongoDB

```bash
sudo apt update
sudo apt install -y mongodb-org
```

### Step 5: Start and enable MongoDB service

```bash
sudo systemctl start mongod
sudo systemctl enable mongod
sudo systemctl status mongod
```
