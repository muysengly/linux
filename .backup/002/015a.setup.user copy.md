## User Management

### Creating a User

```bash
# Basic user creation
sudo adduser username

# Create user with specific options
sudo useradd -m -s /bin/bash username

# Create user with home directory and set shell
sudo useradd -m -s /bin/bash -c "Full Name" username
```

**Common Options:**

- `-m`: Create home directory
- `-s`: Specify login shell
- `-c`: Comment/description
- `-d`: Specify home directory path
- `-g`: Primary group
- `-G`: Supplementary groups

### Setting/Changing Password

```bash
# Set password for a user
sudo passwd username
```

### Modifying Users

```bash
# Modify user properties
sudo usermod -s /bin/bash username  # Change shell
sudo usermod -d /new/home username  # Change home directory
sudo usermod -aG groupname username # Add user to group
```

### Deleting Users

```bash
# Delete user but keep home directory
sudo userdel username

# Delete user and home directory
sudo userdel -r username
```

## Group Management

### Creating a Group

```bash
# Create a new group
sudo groupadd groupname

# Create group with specific GID
sudo groupadd -g 1005 groupname
```

### Adding Users to Groups

```bash
# Add user to group
sudo usermod -aG groupname username

# Add multiple users to group
sudo gpasswd -M user1,user2,user3 groupname
```

### Modifying Groups

```bash
# Change group name
sudo groupmod -n newname oldname

# Change group GID
sudo groupmod -g 1006 groupname
```

### Deleting Groups

```bash
# Delete a group
sudo groupdel groupname
```

## Practical Examples

### Example 1: Create Developer User with Group

```bash
# Create development group
sudo groupadd developers

# Create user with home directory and add to developers group
sudo useradd -m -s /bin/bash -G developers john

# Set password
sudo passwd john
```

### Example 2: Create System User for Service

```bash
# Create system user without login capabilities
sudo useradd -r -s /bin/false -d /opt/myservice myservice
```

### Example 3: Create User with Specific UID and GID

```bash
# Create group with specific GID
sudo groupadd -g 2001 webadmins

# Create user with specific UID and primary group
sudo useradd -u 1001 -g webadmins -m -s /bin/bash adminuser
```

## Useful Commands for User/Group Management

### Viewing Information

```bash
# Show user information
id username
finger username

# Show group information
getent group groupname
groups username

# List all users
getent passwd
cut -d: -f1 /etc/passwd

# List all groups
getent group
cut -d: -f1 /etc/group
```

### File Permissions

```bash
# Change file ownership
sudo chown username:groupname filename

# Change directory ownership recursively
sudo chown -R username:groupname directory/
```

## Important Files

- `/etc/passwd` - User account information
- `/etc/shadow` - Encrypted passwords
- `/etc/group` - Group information
- `/etc/gshadow` - Group passwords
- `/home/` - User home directories

## Best Practices

1. **Use descriptive usernames** that identify the user's purpose
2. **Assign users to appropriate groups** based on their roles
3. **Use `adduser` instead of `useradd`** for interactive creation (more user-friendly)
4. **Always use `-aG` with `usermod`** to append to groups rather than replace
5. **Regularly audit users and groups** to maintain system security
